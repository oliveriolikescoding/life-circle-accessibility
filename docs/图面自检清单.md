# 图面自检清单（出图前逐条过）

> 来源：`metro-coverage-analysis/docs/标准符合性审查-SV-01.md` 的 16 项判定 + 8 项缺口。
> 用法：每张专题图导出前，把下面 16 条从上往下过一遍，**不过的当场改**；改不了的写进「缺口登记」，不许默默放过。
> 每次自检结果追加在文末「自检记录」，留痕。

## 一、16 条必过项

### A. 图幅与范围（决定「结论是否看得见」）

- [ ] **A1 图幅覆盖全部专题要素**：最远的那个点/最大值那个单元必须在图内，不能出现「README 写 9.1 km、图上却看不到」。
- [ ] **A2 图幅比例与数据长宽比一致**：地图框宽高比 = 数据外包宽高比，不许拉伸变形；宁可留白也不拉。

### B. 坐标与尺度的可读性（决定「读者能不能量」）

- [ ] **B3 投影与基准声明**：图廓外写明 CRS（如 EPSG:32648 / WGS 84）、基准、单位（米），不许只写「成都」。
- [ ] **B4 比例尺是换算出来的，不是写死的**：分段黑白比例尺 + km 单位 + 「1:N（按本图幅纸面尺寸换算）」，N 由实际图幅算，不许硬编码。
- [ ] **B5 图廓与坐标注记**：双线图廓 + 公里格网注记（E/N，km）；横边数字水平、竖边数字竖排，注记在图框外。

### C. 定位与参照（决定「这是哪儿」）

- [ ] **C6 有地理参照**：叠加行政界线/主要道路/水系等底图，读者能定位；底图来源与「非法定界线」声明同行写明。
- [ ] **C7 指北针**：右上角，注明投影北向即图面正上（不做磁偏角修正时须说明）。

### D. 色彩与符号（决定「话有没有说反」）

- [ ] **D8 配色语义正确**：好=冷色（青绿），差=暖色（赭红/砖红），不许把「覆盖内」涂成红色这种反向语义。
- [ ] **D9 不只靠颜色区分**：每档必须「颜色 + 形状（或线型）+ 尺寸」至少两重编码；**转灰度后仍能分出全部档位**才算过。
- [ ] **D10 对比度自检 ≥ 3:1**：所有要素色对白底跑一遍 WCAG SC 1.4.11（非文本 3:1），脚本每次出图自动打印，不靠肉眼。
- [ ] **D11 要素有主从**：背景底图降权（浅灰、细线），专题要素最重；同一图层内点符号不许大到糊成一片。

### E. 注记与版式（决定「能不能读」）

- [ ] **E12 注记避让**：注记不压盖要素、不互相重叠；密集区用引线 + 多方向避让；图例矩形与指北针区域纳入避让区。
- [ ] **E13 一图一职责、有主从**：主图 1 个、副图 ≤ 2 个且标题字号明显小于主标题；左右两栏不许同级争夺注意力。
- [ ] **E14 区县/地名层级**：地名注记在最上层、带白描边、字号 ≥ 6 pt，不许被专题图层压住。

### F. 图廓外注记成套（决定「能不能交付」）

- [ ] **F15 八件套齐全**：图名 / 图号 / 比例尺 / 投影 / 数据来源（含抓取时间）/ 制图日期 / 方法声明（直线距离 or 路网）/ 合规声明（非标准地图、对外发布需审图）。
- [ ] **F16 来源可追溯**：每个数据源单列，带许可（OSM 须写 ODbL + 抓取月份），底图来源不能省。

## 二、缺口登记（改不了的写这里，不许藏）

| 编号 | 缺口 | 触发条件 | 处置 |
|---|---|---|---|
| H-01 | 无国家审图号 | 任何对外发布/商业交付 | 图面声明「非标准地图」，交付前提示客户送审 |
| H-02 | 底图为 DataV 行政界线 | 用该底图时 | 图面写「非法定界线」 |
| H-03 | 未用 CGCS2000 | 国内正式测绘成果 | 图面写实际基准，交付时说明差异 |
| H-04 | 距离为直线距离 | 任何可达性分析 | 图面与方法声明同时写「非路网/步行距离」 |
| H-05 | 第三方数据未与官方名录核对 | OSM 等开放数据 | README 与图面注明样本量与风险 |
| H-06 | 静态图不适用 WCAG | 引用无障碍标准 | 只引用对比度建议，不宣称合规 |
| H-07 | 密集区符号仍难分辨 | 点位 > 1000 个 | CSV 补偿 + README 说明 |
| H-08 | 图上只标部分代表要素 | 注记数量受限 | 图面注明总数，明细进 CSV |
